🐚 关于小螺号康复精选

小螺号康复精选（RehabHot）是一个面向言语治疗师、康复从业者和特殊儿童家长的每日自动资讯聚合平台。

系统每日从以下权威来源自动抓取最新内容，通过五维评分算法精选最有价值的文章，帮助您节省信息筛选时间，专注于真正重要的事情——帮助孩子康复。

覆盖领域：构音障碍 · 语言发育迟缓 · 听力障碍 · 孤独症谱系障碍

  • 实用度 25% — 家庭干预方案、临床策略、工具模板
  • 前沿度 20% — 近期发表（30天内最高），保证内容时效性
  • 权威度 25% — 来源机构评级（WHO=95 / ASHA=88 / PubMed=87）
  • 适用面 15% — 覆盖儿童/家长/治疗师范围
  • 通俗度 15% — 摘要可读性，无过度专业术语

评级标准：≥74分 = 🏆精选推荐 | 70-73分 = 优质内容 | 65-69分 = 参考阅读

🤖 技术架构

  • 爬虫：Python（urllib + BeautifulSoup + feedparser），每次运行约20-30秒，可部署至云服务器或 Cloudflare Workers
  • 数据存储：JSON文件（articles.json + data.js），直接被前端引用，无需后端
  • 前端：纯静态 HTML/CSS/JS，支持全文搜索 + 分类过滤
  • 部署：可部署至 GitHub Pages / Cloudflare Pages / 任意静态托管
  • 自动化：配合 cron job 或 Cloudflare Workers Cron，每日 06:00 / 18:00 自动抓取更新
